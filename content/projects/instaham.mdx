InstaHAM is a mobile computer vision app that estimates the live weight and
health of pigs from RGB images. Models for image segmentation, health
classification, and weight estimation were trained and fine-tuned while testing
different combinations; the best combination was converted from Python to C++
and deployed as a lightweight app through Flutter. It was built by a team of
four using Git workflows and the native Flutter build to ship prototypes.
